# Section B – System Design

This folder contains the design documentation for the Skool-Comm School-Parent Communication App.

## Design Documents

- **System Architecture Diagram:** Shows the Flutter mobile application, ASP.NET Core web application and shared Supabase backend.
- **Entity Relationship Diagram (ERD):** Shows the database entities and their relationships.
- **UML Use Case Diagram:** Shows the system actors and their interactions with Skool-Comm.
- **Interface Documentation:** Describes the application's user interfaces and screen designs.
